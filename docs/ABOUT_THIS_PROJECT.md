# ABOUT_THIS_PROJECT

このリポジトリは、Ralph Wiggum パターンを体験するための最小スターターです。

以前のように、作るもの・使う技術・実行環境を細かく決めるためのリポジトリではありません。
Ralph を試す人が、自分の題材と道具を選べる状態を保ちます。

## 含まれているもの

- `ralph.sh`: headless ループを回すスクリプト
- `.claude/skills/ralph-plan/`: Ralph 用スプリントを準備する skill
- `.claude/skills/grill-me/`: 対話で計画を詰める skill
- `ralph/sprints/`: スプリントを置く場所
- `docs/`: Ralph の説明

## 含めないもの

- 特定アプリの詳細仕様
- 特定フレームワーク前提の設計
- 固定のディレクトリ設計
- 固定のテスト・lint・ビルドコマンド

それらは、実際に試すスプリントの中で決めます。
