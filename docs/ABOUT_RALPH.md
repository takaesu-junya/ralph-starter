# ABOUT_RALPH

Ralph は、AI に同じ指示を繰り返し渡しながら、長めの作業を小さな単位で進める運用パターンです。

このリポジトリでは、次の 2 段階に分けています。

## 1. 準備する

対話モードで `ralph-plan` を使い、Ralph に渡すスプリントを作ります。

```text
/ralph-plan <やりたいこと> の Ralph スプリントを準備して
```

スプリントには、Ralph が読む入力と、Ralph が追記していく状態ファイルが入ります。

## 2. ループを回す

```sh
./ralph.sh ralph/sprints/<sprint-name> [N]
```

`N` は最大イテレーション数です。途中で止めても、ファイルと Git 履歴に進捗が残ります。

## このスターターの考え方

このリポジトリは「何を作るべきか」や「どの技術を使うべきか」を決めません。

Docker を使っても、使わなくても構いません。PHP / Laravel でも、Rust でも、ほかの道具でも構いません。
ライブラリを使っても、自作しても構いません。

ここに残すのは、Ralph の流れを試すための最小限の説明だけです。
